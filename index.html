1.1 基本概念
概念定义示例

组合成符号表达式
示例：
“今天下雨或者明天下雨” → P ∨ Q “今天刮风并且明天下雨” → P ∧ Q

考点3析取▼
3.1 同或 vs 异或
类型定义含义
同或两边可以同时成立两边至少有一个成立（三种情况）

“今天我要么上班要么休息” → 异或 → D. (¬q ∧ p) ∨ (q ∧ ¬p)

示例：对于变项 p, q，小项有：p∧q, p∧¬q, ¬p∧q, ¬p∧¬q。 2.2 小项的表示 以 P, Q 两个原子命题为例：

2.4 求解方法：真值表法（优先） 列出真值表：列出所有命题变项的真值指派（从全1到全0）。
找出真值为1的行：在公式值为1的每一行，写出对应的小项（变项取1写本身，取0写否定）。
析取连接：将这些小项用析取符号（∨）连接，即得主析取范式。 原理：命题公式的主析取范式就是所有使其为真的赋值对应小项的析取。
2.5 求解方法：等值演算法（次选） 化简形式：通过等值演算，将公式化为析取范式形式。
补全小项：对于每个析取项（合取式），通过“添项”技巧，使用 A∧(B∨¬B) ≡ A 将缺失的变项补全，使其变成小项。 整理结果：利用幂等律 A∨A≡A 去掉重复项，并按小项的二进制表示排序。 技巧：如果题目明确要求用等值演算但推不出来，可以用真值表法得出答案，再反向书写简单的演算过程。

考点3主合取范式▼
3.1 概念 定义：若干大项按照合取（∧） 连接构成的公式。 大项 (Maxterm)：命题变项及其否定的析取式，每个变项出现且仅出现一次。
与小项的关系：大项是小项的否定。即 Mᵢ = ¬mᵢ。 3.2 大项的表示 以 P, Q 两个原子命题为例：
大项简写编码
P ∨ QM₀₀M₀
P ∨ ¬QM₀₁M₁
¬P ∨ QM₁₀M₂
¬P ∨ ¬QM₁₁M₃
3.3 求解方法：真值表法（优先） 列出真值表：同主析取范式。
找出真值为0的行：在公式值为0的每一行，写出对应的大项（变项取0写本身，取1写否定）。
合取连接：将这些大项用合取符号（∧）连接，即得主合取范式。 原理：命题公式的主合取范式就是所有使其为假的赋值对应大项的合取。
3.4 求解方法：等值演算法（次选） 化简形式：通过等值演算，将公式化为合取范式形式。
补全大项：对于每个合取项（析取式），通过“添项”技巧，使用 A∨(B∧¬B) ≡ A 将缺失的变项补全，使其变成大项。 整理结果：利用幂等律 A∧A≡A 去掉重复项。 3.5 示例讲解：(p∨q) ∧ (q→¬r) 的主合取范式 方法一：真值表法 (接2.7节真值表)

考点4大小项个数▼
4.1 判断规则
条件计算方法
小项个数真值表中结果为1的个数
大项个数真值表中结果为0的个数
*
4.2 关键关系 对于包含 n 个命题变元的公式：
其主析取范式包含的 小项个数 = 真值表中结果为 1 的行数。
其主合取范式包含的 大项个数 = 真值表中结果为 0 的行数。
关键关系：小项个数 + 大项个数 = 2ⁿ
4.3 典型例题分析 例1：命题公式 P→Q 的主析取范式中含小项的个数是？ 解：画出 P→Q 的真值表，结果为1的行有3行，故小项个数为3。答案选 C。 例2：设命题公式 A 含有2个命题变元，且已知 A 为矛盾式，则 A 的主合取范式含大项的个数为？
解：矛盾式意味着所有赋值下公式值为0。2个变元有 2²=4 种赋值，因此大项个数为4。答案选 C。
例3：命题公式 ¬(P∧Q) → R 的主合取范式中含大项的个数。 解：画出该公式的真值表（3个变元，共8行），找出值为0的行数。经计算，值为0的行有6行，故大项个数为6。
例4：包含 n 个命题变项的重言式的主析取范式包括小项的个数为？
解：重言式在所有赋值下为真。n个变元有 2ⁿ 种赋值，因此小项个数为 2ⁿ。答案选 A。
例5：若含 n(n≥2) 个命题变项的命题公式 A 为可满足式，则 A 的主合取范式中最多含有 2ⁿ - 1 个大项。
解：可满足式意味着至少有一个赋值使其为真（小项个数 X ≥ 1）。由于 X + Y = 2ⁿ，当 X 最小为1时，Y 最大为 2ⁿ - 1。
考点5小项与大项的性质▼
5.1 核心性质总结 任意不同小项的合取为假 (F)：mᵢ ∧ mⱼ ≡ F (i ≠ j) 任意不同大项的析取为真 (T)：Mᵢ ∨ Mⱼ ≡ T (i ≠ j) 大项的否定是小项，小项的否定是大项：¬Mᵢ ≡ mᵢ， ¬mᵢ ≡ Mᵢ 5.2 性质证明与举例 证明“任意不同小项的合取为假”：
任取两个不同小项，例如 m₁ = p∧q 和 m₂ = p∧¬q。 m₁ ∧ m₂ = (p∧q) ∧ (p∧¬q) = p ∧ (q ∧ ¬q) = p ∧ F ≡ F 证明“任意不同大项的析取为真”：

任取一个大项，例如 M₂ = ¬p∨q。 ¬M₂ = ¬(¬p∨q) = p ∧ ¬q。这正是小项 m₁（对应指派 p=1, q=0）。

考点7自然推理规则（CP规则）▼
利用等值式或蕴含式得出结论，然后将该结论作为前提，继续执行上述步骤，直到得出所求结论，推理得证。主要规则：1. P规则（前提引入规则）任何前提都可直接作为结论，即“H⇒H”。2. T规则（置换规则）之前已得出的结论可以通过等值式或蕴含式转为另一个结论。3. CP规则
CP规则（附加前提）当要证明的结论是蕴涵式（如 A → B）时，将前件 A 作为附加前提引入，然后推出后件 B，即可证明 A → B 成立。 4. 归谬法要证明一个结论 C 是一组前提 H₁, H₂, ..., Hn 的有效结论，可以假设结论 C 为假（即 ¬C 为真），并将这个假设作为一个附加前提加入到原有的前提集合中。如果从这个扩大的前提集合中，最终能推出一个矛盾（如 P ∧ ¬P 或 F），则说明假设 ¬C 不成立，从而证明原来的结论 C 为真，推理有效。
