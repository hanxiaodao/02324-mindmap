考点1命题符号化▼
1.1 基本概念
概念定义示例
命题具有唯一真值的陈述句（真或假）"今天下雨"
原子命题不能再拆分的命题（用 P,Q,R…表示）"今天下雨"
复合命题原子命题连起来（把 P,Q,R 组合起来）"今天下雨或者明天下雨"
联结词把 P,Q,R 连起来的纽带或、且、非 等
命题符号化把文字转化成符号P ∨ Q
1.2 命题符号化的关键 核心步骤：准确使用联结词
· 先找出原子命题，用 P,Q,R 表示
· 确定原子命题之间的联结词
· 组合成符号表达式
示例：
"今天下雨或者明天下雨" → P ∨ Q
"今天刮风并且明天下雨" → P ∧ Q
考点2否定（¬）与合取（∧）▼
2.1 五个联结词
序号名称符号含义
1否定¬非（取反）
2合取∧且（同时成立）
3析取∨或（至少一个成立）
4单条件→推出（前件推后件）
5双条件↔当且仅当（双向推出）
2.2 否定（¬） 符号：¬   读法："非"   含义：取反
示例：¬P 表示"非P"，P = "今天下雨" → ¬P = "今天没下雨" 2.3 合取（∧） 符号：∧   含义：且（同时成立）  特点：两边都为真才为真
例题：设 P:小张是数学老师，Q:小张是计算机老师
"小张既是数学老师又是计算机老师" → P ∧ Q
考点3析取（∨）/ 同或与异或▼
3.1 同或 vs 异或
类型定义含义
同或两边可以同时成立两边至少有一个成立（三种情况）
异或两边不能同时成立两边其中一个成立（两种情况）
3.2 析取符号（∨） 符号：∨   含义：或（同或）  特点：两边至少有一个成立
示例："今天刮风或今天下雨" → P ∨ Q（同或，可同时成立） 3.3 异或的表示 异或可表示为：(P ∧ ¬Q) ∨ (¬P ∧ Q) 3.4 例题 例1："小张是数学老师或体育老师" → P ∨ Q
例2："今天我要么上班要么休息" → 异或 → D. (¬q ∧ p) ∨ (q ∧ ¬p)
考点4单条件（→）▼
4.1 单条件符号（→） 符号：→   含义：推出（前件推后件）  注意：P → Q 为前推后 4.2 前推后 vs 后推前
表达式含义示例
P → QP推出Q（前推后）"只要努力就会成功" → 努力 → 成功
Q → PQ推出P（后推前）"只有努力才会成功" → 成功 → 努力
4.3 关键词判断
关键词推导方向示例
因为…所以…前推后因为今天不下雨，所以我今天进城 → ¬P → Q
只要…就…前推后只要天不下雨，小王就会早到 → ¬P → Q
只有…才…后推前只有努力才会成功 → 成功 → 努力
除非…否则不先转为"只有…才"，再后推前除非努力否则不成功 → 成功 → 努力
4.4 例题 例1："只要努力就会成功" → 努力 → 成功
例2："只有努力才会成功" → 成功 → 努力
例3："除非努力否则不成功" = "只有努力才会成功" → Q → P
例4：令 p:今天下雨，q:我今天进城，"因为今天不下雨，所以我今天进城" → ¬p → q
考点5双条件（↔）▼
5.1 双条件符号（↔） 符号：↔   含义：双向推导出   特点：两边同时成立或者同时不成立
关键词："当且仅当"、"充分必要" 5.2 示例 P ↔ Q 表示 P 和 Q 保持一致
"小张是数学老师当且仅当小张是体育老师" → P ↔ Q

考点10永真式 & 永假式▼
10.1 定义
名称定义
永真式（重言式）命题公式永远是真的，即真值表全为1

第二章 · 范式7考点▼
考点1范式基本概念▼
1.1 定义 范式（Normal Form）：即规范的形式，是命题公式的标准化。 1.2 重要概念
概念定义构成
小项原子命题合取连接P∧Q, P∧¬Q 等
大项原子命题析取连接P∨Q, P∨¬Q 等
主析取范式小项按照析取连接(P∧Q)∨(¬P∧Q)
主合取范式大项按照合取连接(P∨Q)∧(¬P∨Q)
考点2主析取范式▼
2.1 概念 定义：若干小项按照析取（∨）连接构成的公式。
小项 (Minterm)：命题变项及其否定的合取式，每个变项出现且仅出现一次。 2.2 小项的表示（两个变元）
小项简写编码
P∧Qm₁₁m₃
P∧¬Qm₁₀m₂
¬P∧Qm₀₁m₁
¬P∧¬Qm₀₀m₀
2.3 三个原子命题的小项
序号小项编码
1P∧Q∧Rm₇
2P∧Q∧¬Rm₆
3P∧¬Q∧Rm₅
4P∧¬Q∧¬Rm₄
5¬P∧Q∧Rm₃
6¬P∧Q∧¬Rm₂
7¬P∧¬Q∧Rm₁
8¬P∧¬Q∧¬Rm₀
2.4 求解方法：真值表法（优先） · 列出真值表 → 找出真值为1的行 → 写出小项 → 析取连接 2.5 求解方法：等值演算法（次选） · 化简为析取范式 → 添项补全小项 A∧(B∨¬B) ≡ A → 幂等律去重
技巧：推不出来时可用真值表法得出答案再反向写简单的演算过程 2.6 示例：(p→q)∧r 真值表法：真值为1的行：(p∧q∧r),(¬p∧q∧r),(¬p∧¬q∧r)\n主析取范式：∑(1,3,7)\n等值演算法：(p→q)∧r⇔(¬p∨q)∧r⇔(¬p∧r)∨(q∧r)⇔...⇔m₃∨m₁∨m₇ 2.7 示例：(p∨q)∧(q→¬r) 真值为1的行对应小项：p∧q∧¬r(m₆), p∧¬q∧r(m₅), p∧¬q∧¬r(m₄), ¬p∧q∧¬r(m₂)
主析取范式：∑(2,4,5,6)
考点3主合取范式▼
3.1 概念 定义：若干大项按照合取（∧）连接构成的公式。
大项 (Maxterm)：命题变项及其否定的析取式，每个变项出现且仅出现一次。
与小项的关系：大项是小项的否定。Mᵢ = ¬mᵢ。 3.2 大项的表示（两个变元）
大项简写编码
P∨QM₀₀M₀
P∨¬QM₀₁M₁
¬P∨QM₁₀M₂
¬P∨¬QM₁₁M₃
3.3 求解方法 真值表法：找值为0的行 → 写出对应大项（变项取0写本身，取1写否定）→ 合取连接
等值演算法：化简为合取范式 → 添项补全 A∨(B∧¬B) ≡ A → 去重 3.4 示例：(p∨q)∧(q→¬r) 的主合取范式 真值为0的行：p∨q∨r(M₀), p∨¬q∨r(M₅), ¬p∨¬q∨r(M₇)
主合取范式：M₀∧M₅∧M₇ 或 ∏(0,5,7)
等值演算法：∏(0,1,5,7)
考点4大小项个数▼
4.1 判断规则 小项个数 = 真值表中结果为1的个数
大项个数 = 真值表中结果为0的个数
关键关系：小项个数 + 大项个数 = 2ⁿ 4.2 典型例题 例1：P→Q 的小项个数 = 3（真值表3行1）
例2：矛盾式（2变元）的大项个数 = 4（全0）
例3：重言式（n变元）的小项个数 = 2ⁿ
例4：可满足式（n变元）的大项最多 2ⁿ-1 个
考点5小项与大项的性质▼
· 任意不同小项的合取为假：mᵢ∧mⱼ ≡ F (i≠j)
· 任意不同大项的析取为真：Mᵢ∨Mⱼ ≡ T (i≠j)
· 大项的否定是小项：¬Mᵢ ≡ mᵢ；小项的否定是大项：¬mᵢ ≡ Mᵢ
证明：m₁=p∧q, m₂=p∧¬q → m₁∧m₂ = p∧(q∧¬q) ≡ F

考点7自然推理规则（CP规则）▼
主要规则：
1. P规则（前提引入规则）：任何前提都可直接作为结论，即"H⇒H"。
2. T规则（置换规则）：已得出的结论可通过等值式或蕴含式转为另一个结论。
3. CP规则（附加前提）：当结论是蕴涵式 A→B 时，将前件 A 作为附加前提引入，推出后件 B 即可。
4. 归谬法：假设结论 C 为假（¬C），加入前提推出矛盾，则 C 为真。

考点1谓词和量词▼
1.1 基本概念
概念定义符号
谓词表示对象具有某种性质P(x), A(x)
个体词（常指）具体对象小张、小王
个体词（变元）不特定指哪一个x, y
论域个体词的取值范围全体实数、自然数等
1.2 量词
量词符号含义
全称量词∀所有、每一个
存在量词∃至少有一个、存在
∀x P(x)：论域中所有 x 都满足性质 P
∃x P(x)：论域中至少存在一个 x 满足性质 P
考点2谓词符号化▼
2.1 基本规则
语句类型符号化方式
是什么使用单条件（→）
不是什么使用合取非（∧¬）
例1："所有的胖人都是懒的" → ∀x(P(x)→L(x))
例2："存在胖的人不是懒的" → ∃x(P(x)∧¬L(x))
全称量词常与→配合；存在量词常与∧配合
考点3谓词公式的真假▼
3.1 判断方法
量词为真条件为假条件
∀每一个都满足只要有一个不满足
∃只要有一个满足全都不满足
示例：论域为整数，∀x(x²≥1) → x=0时0²=0<1 → 为假
∀x∃y(x²为真
考点4量词的辖域▼
4.1 判断规则 · 量词后没有括号 → 辖域是紧邻的谓词
· 量词后有括号 → 辖域是整个括号内容
示例：∀x P(x) → 辖域是 P(x)；∀x(P(x)→Q(x)) → 辖域是整个括号内
考点5约束变元和自由变元▼
概念定义
指导变元量词后面的个体词
约束变元辖域内与指导变元相同的个体词
自由变元辖域内与指导变元不同的个体词
∀x(P(x)→Q(y))：辖域 P(x)→Q(y)，指导变元 x
约束变元：P(x)中的x   自由变元：Q(y)中的y
换名规则：约束变元可改名（不影响公式真值）
考点6量词的消去（特化/推广）▼
6.1 等价形式 ∀x P(x) ⇔ P(a)∧P(b)∧P(c)∧…
∃x P(x) ⇔ P(a)∨P(b)∨P(c)∨… 6.2 推理规则 全称特化（UI）：∀x P(x)→P(a)
存在特化（EI）：∃x P(x)→P(c)
全称推广（UG）：P(y)→∀x P(x)
存在推广（EG）：P(a)→∃x P(x)
考点7谓词恒等式▼
¬∀x P(x) ⟺ ∃x ¬P(x) ¬∃x P(x) ⟺ ∀x ¬P(x) ∀x(P∧Q) ⟺ ∀xP ∧ ∀xQ ∃x(P∨Q) ⟺ ∃xP ∨ ∃xQ 注意：后两个公式是单向的（左→右成立，右→左不成立）
考点8前束范式▼
定义：所有量词都在最前面，辖域为整个公式的形式。
形式：Q₁x₁ Q₂x₂ … Qₙxₙ M(x₁…xₙ)
任何谓词公式都可化为等值的前束范式。
转化步骤：改名 → 消除→（改为¬∨）→ 移动量词到前面
考点9谓词推理▼
核心规则：全称成立则单个成立。∀x P(x) → P(c)
步骤：写前提 → 用特化消去量词 → 用命题规则推理 → 用推广引入量词
示例：条件1：∀x(P(x)→Q(x))，条件2：P(小华)，结论：Q(小华)
证明：① ∀x(P(x)→Q(x))   ② P(小华)→Q(小华)   ③ P(小华)   ④ Q(小华)

考点2子集 & 真子集▼
子集 A⊆B：A的每个元素都在B中（可取全部）
真子集 A⊊B：A⊆B且A≠B（不能取全部）
· 空集是任意集合的子集

A={1,2,3}：子集8个（含自身），真子集7个（不含自身）
考点3幂集▼
幂集 P(A)：A的所有子集构成的集合（符号：P(A)或2^A）
|A|=n → |P(A)|=2ⁿ A={1,2}：P(A)={∅,{1},{2},{1,2}}   |P(A)|=2²=4
考点4集合运算（∪∩−∁）▼
运算符号含义
交集A∩B两个集合重合的部分
并集A∪B合并（重复只算一次）
差集A−B从A中去掉与B重合的部分
补集∁A属于全集但不属于A
德摩根：∁(A∪B)=∁A∩∁B   ∁(A∩B)=∁A∪∁B A={1,2,3,4},B={2,4,5,6}：A∩B={2,4} A∪B={1,2,3,4,5,6} A−B={1,3}
考点5对称差（A⊕B）▼
A⊕B = (A∪B)−(A∩B) = (A−B)∪(B−A) 即：属于A或B，但不同时属于两者的元素。
A={1,2,3},B={2,3,4}：A⊕B={1,4}
考点6笛卡尔积（A×B）▼
有序对（序偶）：(a,b) 前后顺序有区别。
A×B：从A取第一元素，从B取第二元素，组成所有可能的有序对。
|A×B| = |A|×|B| A={1,2},B={3,4}：A×B={(1,3),(1,4),(2,3),(2,4)} |A×B|=4
考点7笛卡尔积的性质▼
· A×B ≠ B×A（一般情况下顺序不同）
· A×∅ = ∅
· A×(B∪C) = (A×B)∪(A×C)（分配律）
· A×(B∩C) = (A×B)∩(A×C)（分配律）

5.25命题逻辑推理▼
直接证明法——常用推理规则：
· 分离规则：P→Q且P，可得Q
· 析取三段论：P∨Q且¬P，可得Q
· 合取消去：P∧Q，可得P或Q
· 双条件分解：P↔Q，可得P→Q或Q→P

归谬法（反证法）：
要证Q为真，先假设¬Q为真，加入前提推理；若推出矛盾（如P∧¬P），则¬Q不成立，故Q为真。

示例：{P∧Q, Q→¬R, R∨S} ⊢ S
① P∧Q（前提）
② Q（由①，合取消去）
③ Q→¬R（前提）
④ ¬R（由②③，分离规则）
⑤ R∨S（前提）
⑥ S（由④⑤，析取三段论）

6.1二元运算 & 封闭性▼
二元运算：两个元素进行某种运算
封闭性：运算结果仍在集合内
正整数加法：封闭（正整数+正整数=正整数）
正整数减法：不封闭（1-2=-1不在正整数集中）
6.2五大运算性质▼
结合律：(a∘b)∘c = a∘(b∘c)
交换律：a∘b = b∘a
幂等律：a∘a = a
分配律：a∘(b★c) = (a∘b)★(a∘c)
消去律：不要求掌握
减法不满足结合律：(a-b)-c ≠ a-(b-c)
减法不满足交换律：a-b ≠ b-a
6.3幺元（单位元）▼
幺元 e：所有元素与e运算后仍等于自己
e∘a = a∘e = a（对所有a成立） 加法幺元=0，乘法幺元=1，并集幺元=∅，交集幺元=全集
幺元唯一
6.4零元▼
零元 θ：所有元素与θ运算后仍等于θ
θ∘a = a∘θ = θ（对所有a成立） 乘法零元=0，交集零元=∅
非平凡群（≥2个元素）不存在零元
6.5逆元▼
a的逆元 a⁻¹：a与a⁻¹运算等于幺元
a∘a⁻¹ = a⁻¹∘a = e 求逆元必须先求幺元e
加法逆元=相反数；乘法逆元=倒数
6.6-6.8半群→独异点→群▼
代数系统封闭结合幺元逆元
半群✓✓——
独异点✓✓✓—
群✓✓✓✓
自然数集+加法=独异点（没有负数逆元，不是群）
6.9群的阶数 & 元素的阶▼
群的阶 |G|：群中元素的个数
平凡群：只有幺元一个元素
n阶循环群中，aᵏ的阶=n/gcd(n,k) 非平凡群（≥2个元素）不存在零元
6.10交换群（阿贝尔群）▼
在群的基础上再加：交换律（a∘b=b∘a）
条件：封闭+结合+幺元+逆元+交换
6.11环与域▼

8.1图的基本概念 & 度数▼
图 G=(V,E)：顶点集V+边集E
简单图：无重复边、无自环
度数 d(v)：顶点v连接的边数
n阶简单图，某顶点度数≤n-1
8.2握手定理▼
∑d(v)=2|E|（总度数=2倍边数） 推论：总度数一定是偶数
应用：度数序列之和为奇数→不能构成无向图
例：{1,1,3,4}，和=9（奇数）→不能构成
8.3完全图 Kₙ▼
每个顶点都与其余所有顶点相连
Kₙ的边数=n(n-1)/2 K₃=3条边，K₄=6条边，K₅=10条边
8.4正则图▼
k-正则图：每个顶点度数都为k
3-正则图：n个人每人恰有3个朋友
总度数=3n=2|E|（偶数）→n必须为偶数
8.5补图▼
原图补上之后变成完全图→补图
补图边数=n(n-1)/2-原图边数 补图可以旋转拉伸，但不改变连接结构
8.6同构▼
两个图看上去不同，但结构相同（只是摆放方式不同）
5阶非同构的树共3棵：路径图/有3度结点的树/星形图
8.7自补图▼
补图与原图同构→自补图
自补图边数=n(n-1)/4→n(n-1)能被4整除 即n≡0或1(mod4)
8.8连通图 & 非连通图▼
连通图：任意两顶点间有通路
n阶连通图最少边数=n-1（树）
n阶非连通图最多边数=(n-1)(n-2)/2
让1个顶点落单，其余n-1个构成完全图
8.9割边（桥）▼
去掉某条边后图从连通变不连通→该边为割边（桥）
树的每一条边都是割边
8.10邻接矩阵▼
用矩阵表示图的连接关系
无向图：邻接矩阵对称（一条边对应两个1）
有向图：邻接矩阵不一定对称
8.11通路与回路▼
Aᵏ中(i,j)元素=从i到j长度为k的通路数 通路总数=Aᵏ所有元素之和
回路数=Aᵏ对角线元素之和
8.12完全二分图 K(m,n)▼
顶点分两个阵营，阵营内部不连边，左边每个与右边每个都连边
顶点数=m+n；边数=m×n A中顶点度数=n；B中顶点度数=m
第九章 · 树10节▼
9.1欧拉回路 & 欧拉图▼
欧拉回路：从某点出发，经过每条边有且仅一次，最后回到出发点
欧拉图中不存在奇点（度数为奇数的顶点） 判断：检查是否存在度数为奇数的顶点
9.2哈密顿回路▼
哈密顿回路：经过每个节点有且仅一次，最后回到出发点
与欧拉回路的区别：欧拉回路要求每条边都走，哈密顿回路只要求每个点都经过
没有严格的判断方法，只能尝试走一遍
9.3树的基本概念▼
树：连通且无回路的无向图
重要结论：树的边数=节点数-1
特点：连通、无回路、无向图
4阶树边数=3，4阶完全图边数=6，需增加3条边
9.4树的节点分类▼
分支节点：度数>1的节点
叶节点（树叶）：度数=1的节点
6阶树：最多4个分支节点（直链），最多5个树叶（星形）
9.5树的握手定理▼
树的总度数=2×(节点数-1) 即∑d(v)=2(n-1)，其中n为节点数
9.6克鲁斯卡尔算法▼
用于求最小生成树：
1. 将所有节点保留，边全部去掉
2. 从权值最小的边开始连接
3. 如果连接后没有形成圈，则保留该边
4. 如果形成圈，则舍弃该边
5. 重复直到选够n-1条边（n为节点数）
9.7二叉树的概念▼
m叉树：每个节点最多分m个叉
完全m叉树：每个节点要么不分叉，要么分m个叉
正则m叉树：所有叶节点都在同一层
例：完全二叉树7个叶节点→6个分支节点
9.8二叉树的遍历▼
遍历方式顺序别名
先序遍历根→左→右先根
中序遍历左→根→右中根
后序遍历左→右→根后根
示例：给定二叉树，先序（根左右）递归遍历
9.9算术表达式与二叉树▼
给定表达式转换为二叉树：
1. 找到最后运算的符号→作为根节点
2. 左边部分→左子树
3. 右边部分→右子树
4. 递归进行
示例：表达式a+b-c→减号为根，a+b为左子树，c为右子叶

欧拉公式：设有连通平面图G，n个顶点，m条边，r个面，则
