# 02324 离散数学 · 思维导图

全国自考 02324 离散数学考点思维导图（交互式 HTML）。

## 结构

```
├── index.html               # 思维导图页面（可直接浏览器打开）
├── generate.py              # 内容生成脚本（后续接入）
└── .github/workflows/       # 自动部署
```

## 使用

- **浏览器打开** `index.html` 即可离线查看
- **GitHub Pages**：每次手动触发 Workflow 后，访问 Pages 链接获取最新版

## 手动触发部署

1. 在 GitHub 仓库页面点击 **Actions** → **Deploy Mind Map** → **Run workflow**
2. 等待 1-2 分钟
3. 打开 GitHub Pages URL 查看
